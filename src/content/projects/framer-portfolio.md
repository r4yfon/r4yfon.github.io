Framer Portfolio was my first personal website, made in December 2023 when I was starting out in UI and UX design. Rather than learning a framework first, I wanted to see how far the tools already out there could take me, so I built the whole site in Framer without writing any code.

It became a sandbox for design decisions: how to lay out my early projects, which typography and spacing felt right, how page transitions and motion should behave, and how each layout held up on a phone. What I learned here carried into the next version, which I rebuilt in code with Gatsby, and into the one you're reading now.
